# Codex instructions

This repository is a lightweight sandbox for Codex Cloud experiments.

## Setup
- Use Node.js 20 or newer.
- Run `npm install` before starting if dependencies are added later.
- Run `npm test` after making changes.
- Run `npm start` to verify the project starts.

## Working style
- Keep changes small and easy to review.
- Do not commit secrets or API keys.
- Prefer adding dependencies only when they are necessary.
